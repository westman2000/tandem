# 0001. Переносимый контекст разработки

Дата: 2026-10-11. Статус: принято для репозитория приложения.

## Причина

Разработка продолжается в другое время, на разных машинах и с Codex/Claude Code. История конкретного чата, персональная память клиента и машинные навыки не являются достаточным способом передачи проекта.

## Решение

Правила, краткое состояние, карта исходников, план, значимые решения, рабочие записи и проектные навыки хранятся в Git вместе с кодом. `AGENTS.md` — единый текст правил; `CLAUDE.md` импортирует его. Канонические навыки находятся в `.agents/skills`, а скрипт создаёт проверяемые идентичные копии для `.claude/skills`.

STATUS описывает актуальную задачу, worklog сохраняет факты по этапам, Git хранит изменения кода. Полный чат и внутренние рассуждения не копируются в документацию. Входной контекст мал; подробности читаются по карте и задаче.

## Последствия

Новый агент может продолжить из обычного клона без прежней CLI-сессии. Автор должен обновлять записи на значимых контрольных точках. Проверки ловят часть расхождений, но не могут гарантировать соблюдение всех правил агентом. Настройки и авторизация машины остаются локальными.

Отказались от symlink для обязательных инструкций/skills: обычные файлы проще переносить на Windows. Генерируемые копии не редактируются вручную. Одновременная работа разделяется по веткам/задачам; Git не используется для синхронизации живой SQLite.
