## Запланировано

- Подключаемые CLI: отделить роли от провайдеров; следующий кандидат — Antigravity. Сначала проверить фактические возможности установленного CLI и официальную документацию. Примеры команд в старом архитектурном плане — гипотезы до такой проверки.
- Несколько авторов: задачи, отдельные Git worktrees, интеграция изменений и ревью.
- Удалённые workers: защищённый канал, аутентификация машин, доставка заданий/результатов с восстановлением, права на файлы. Не открывать нынешний локальный HTTP-сервер в интернет как замену этому этапу.
- Передача инструкций и состояния для проектов, создаваемых внутри Tandem. Правила разработки приложения не должны автоматически становиться правилами пользовательской игры.
- Улучшение работы с крупными историями, документами и сравнением редакций по результатам реального использования.
