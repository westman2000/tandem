# Передача контекста разработки

Дата: 2026-10-11. Исполнитель: Codex. Ветка: `main`. База приложения: `09a2642` (0.6.0).

## Запрос

Организовать продолжение работы разными агентами и на разных машинах; общие правила, навыки, поиск нужных файлов и сохранение прогресса. Сохранять исходники в `git@github.com:westman2000/tandem.git`.

## Результат

- Добавлены AGENTS и импортирующий его CLAUDE, STATUS, MAP, HANDOFF, ROADMAP, [решение о контексте](../decisions/0001-portable-agent-context.md).
- Два общих навыка: проверка изменений и передача работы. Скрипт создаёт идентичные обычные файлы для Claude; исходники находятся в `.agents/skills/`.
- Проверка репозитория контролирует входные документы, локальные ссылки, импорт правил, копии skills и отслеживаемые служебные пути. Добавлен CI для этих правил и существующих тестов приложения.
- Настроен origin. Расширены исключения локальных файлов и правила LF для инструкций/скриптов. Исполняемый код приложения и версия 0.6.0 не менялись.

## Проверки

- `npm run skills:sync` и `npm run check:repo` прошли: проверены 70 локальных ссылок, входные документы, импорт CLAUDE, обе пары навыков и отслеживаемые пути.
- В отдельном временном Git-репозитории проверены чистый checkout, отказ на сломанную ссылку, обнаружение и исправление расхождения skills, отказ на принудительно добавленный `.env`, отказ на отдельные конкурирующие правила CLAUDE и успешная повторная проверка после исправлений.
- `node --check` для обоих скриптов и `git diff --check` прошли. YAML четырёх SKILL.md и workflow разобран Ruby/Psych. Штатный Python-валидатор skill-creator не запустился из-за отсутствующего PyYAML; метаданные дополнительно проверены встроенной проверкой репозитория.
- Код приложения не менялся, поэтому Go/UI-тесты и сборки повторно не запускались. Их последний результат для 0.6 сохранён в validation. CI пока подготовлен, не выполнен на GitHub.

Работающая пользовательская база не использовалась; реальных модельных запросов не было.

## Передача

Первоначально проверка remote и попытка `git push -u origin main` остановились на SSH/DNS: `Could not resolve hostname github.com`.

После изменения разрешений среды пользователем повторная проверка SSH прошла: `git ls-remote origin` успешно показал отсутствие опубликованных ссылок. `npm run check:repo` повторно прошёл. Обычный `git push -u origin main` успешно отправил историю до `90735e5`: GitHub подтвердил создание `main`, настроено отслеживание `origin/main`. Force-push не использовался. Ограничение отправки снято; результаты CI на GitHub ещё не проверены.

Следующий продуктовый шаг — проверка сценария папок в Safari на отдельном тестовом проекте, см. [STATUS](../STATUS.md). Отдельно подтвердить загрузку инструкций/skills в новой сессии Claude и первый запуск CI в GitHub. Файлы подготовлены, но эти живые проверки ещё не выполнялись.
