Последняя завершённая версия кода: `09a2642` — папки проектов, перенос и восстановление. Коммит этих записей смотрите через `git log -1 -- docs/STATUS.md`: файл не содержит собственный будущий хэш.

## Сейчас

Сессия завершена контрольной точкой для продолжения на другой машине или другим агентом. Владелец этапа — Codex; активной задачи разработки и незавершённых изменений кода нет. Проверенный исходный коммит этой сессии — `6cce369`. Подготовлены общие инструкции, карта файлов, навыки проверки/передачи, журнал и GitHub Actions. Запись сессии — [сохранение и продолжение](worklog/2026-10-12-session-handoff.md).

Remote `origin`: `git@github.com:westman2000/tandem.git`, `main` отслеживает `origin/main`. Перед этой контрольной точкой локальная и удалённая ветки совпадали на `6cce369`. Проверен [успешный запуск GitHub Actions для этого коммита](https://github.com/westman2000/tandem/actions/runs/38184936719). Результат CI нового коммита нужно проверять отдельно.

Исправлена публичная документация: удалены личные домашние пути, запуск описан для чистого клона. Проверка репозитория отклоняет такие пути в Markdown. Для новых коммитов в локальном Git настроены публичный ник и GitHub noreply-адрес; на другой машине эту настройку нужно повторить. **В 10 ранее опубликованных коммитах личные данные остаются:** очистка истории требует отдельного согласования. Подробности — [исправление публикации](worklog/2026-10-11-public-docs-privacy.md).

## Следующий конкретный шаг

Проверить **новый диалог папок в Safari** на отдельном тестовом проекте: создать, добавить MD, запустить демо, открыть редакцию, сделать независимую копию, перенести и открыть снова. Рабочие проекты пользователя не использовать как тестовые данные. Исправить подтверждённые проблемы до расширения функциональности.

Обратная связь для следующего обсуждения интерфейса: ожидание первого ответа с кодом воспринимается как отсутствие работы. При диагностике был подтверждён запущенный CLI и этап `prototype_code`; зависание не подтверждено. Стоит яснее показывать текущий этап, прошедшее время и ожидание первой сборки. Улучшение пока не реализовано; оно не заменяет выбранную пользователем следующую задачу.

- Новый интерактивный сценарий папок в Safari не проверен. Linux/Windows были кросс-собраны, но не запущены. Тесты не расходовали реальные подписки.
- SSH/DNS работают; отправка на GitHub и CI для `6cce369` подтверждены. Во время предыдущей диагностики локальный сервер отвечал на API и запускал Codex для прототипа. При сохранении этой сессии сервер уже остановлен; запрос к локальному порту отклонён. На новой машине проверить фактические возможности заново.
- В этой сессии код не менялся: локальные проверки правил репозитория и diff прошли; сборка приложения и испытание Safari заново не выполнялись. Не запускайте пользовательские циклы ради проверки передачи.
- Проверки организации репозитория и результат отправки фиксируются в [записи передачи](worklog/2026-10-11-repository-handoff.md).

## Что переносится

Git переносит код Tandem, документы разработки и проектные skills. Пользовательские ТЗ, вложения, прототипы и их журналы в публичный репозиторий не входят. Для продолжения такого проекта на другой машине нужна отдельная копия данных после остановки Tandem; порядок описан в [HANDOFF](HANDOFF.md). Авторизация CLI и черновики браузера через Git не переносятся.

## Пока не реализовано

Удалённые workers/интернет-соединение, синхронизация живой SQLite, произвольные CLI/Antigravity, параллельная интеграция изменений авторов. Подробности и порядок — [ROADMAP](ROADMAP.md).
