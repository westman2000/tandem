# Текущее состояние Tandem

Обновлено: 2026-10-11. Ветка: `main`. Приложение: **0.6.0**.

Последняя завершённая версия кода: `09a2642` — папки проектов, перенос и восстановление. Коммит этих записей смотрите через `git log -1 -- docs/STATUS.md`: файл не содержит собственный будущий хэш.

## Сейчас

Подготовлена передача разработки между машинами и агентами: общие инструкции, карта файлов, навыки проверки/передачи, журнал, проверка правил репозитория и GitHub Actions. Владельцем этого этапа был Codex; следующая задача ещё не взята.

Remote `origin`: `git@github.com:westman2000/tandem.git`. Отправка из среды разработки недоступна: SSH не разрешает имя `github.com`. Изменения нужно отправить из обычного терминала; наличие GitHub-копии пока не подтверждено. Не заменять удалённую историю, если там уже есть другие коммиты.

## Что уже работает

- Обсуждение документов через Codex/Claude, материалы, редакции, утверждения, продолжение доработки.
- Прототип по утверждённому документу: план, автор/рецензент, код, проверки, Git checkpoints, ручная приёмка.
- Доступность участников, сведения о квотах, самостоятельная работа доступного агента и отложенное независимое ревью.
- Восстановление, HTTP-квитанции, браузерные черновики, отдельные папки проектов, перенос/копия/повторное открытие и импорт внешней правки Markdown.

## Следующий конкретный шаг

После сохранения в GitHub проверить **новый диалог папок в Safari** на отдельном тестовом проекте: создать, добавить MD, запустить демо, открыть редакцию, сделать независимую копию, перенести и открыть снова. Рабочие проекты пользователя не использовать как тестовые данные. Исправить подтверждённые проблемы до расширения функциональности.

## Проверено и ограничения

- Код 0.6: Go race-тесты, go vet, Node/React SSR, TypeScript/Vite и сборки пяти платформ прошли; подробности в [validation](validation.md).
- Новый интерактивный сценарий папок в Safari не проверен. Linux/Windows были кросс-собраны, но не запущены. Тесты не расходовали реальные подписки.
- В этой среде ранее были недоступны bind локального порта и SSH/DNS; это ограничения окружения, а не результат теста продукта. На новой машине проверить фактические возможности заново.
- Проверки организации репозитория и результат отправки фиксируются в [записи передачи](worklog/2026-10-11-repository-handoff.md).

## Пока не реализовано

Удалённые workers/интернет-соединение, синхронизация живой SQLite, произвольные CLI/Antigravity, параллельная интеграция изменений авторов. Подробности и порядок — [ROADMAP](ROADMAP.md).
