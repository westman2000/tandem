# Tandem

Локальная мастерская идей: пользователь, Codex и Claude Code обсуждают задачу и совместно готовят техническое задание. Локальный прототип приложения, версия 0.6.0: обсуждение ТЗ, разработка небольшого прототипа, мониторинг участников, восстановление после сбоев и самостоятельные папки проектов.

В браузере — проекты, общий диалог, вкладки участников, материалы, журнал действий и итоговый документ. Go-сервер запускает официальные CLI под текущим пользователем ОС. История и контрольные точки хранятся в SQLite. Закрытие вкладки не останавливает обсуждение.

Для продолжения разработки на другой машине или с другим агентом: [текущее состояние](docs/STATUS.md), [карта папок и исходников](docs/MAP.md), [порядок передачи](docs/HANDOFF.md), [план](docs/ROADMAP.md). Общие правила находятся в [AGENTS.md](AGENTS.md); Claude получает их через [CLAUDE.md](CLAUDE.md). Проверка правил репозитория: `npm run check:repo`.

## Папки проектов (0.6)

«Новый проект» предлагает название и расположение, показывает итоговый путь и создаёт новую подпапку. Выбор папки работает внутри интерфейса, без расширения браузера; можно также вставить путь вручную. Это папки компьютера, где запущен сервер Tandem, его имя видно в окне. По умолчанию новые проекты создаются в `~/Tandem/Projects`; выбранное расположение запоминается.

- **Открыть проект** — выбрать папку с `tandem.project.json`. Незавершённая работа открывается на паузе; команды и агенты сами не запускаются.
- **Выбрать папку и перенести** — для старых проектов из общей базы. Переносится только выбранный проект: обсуждения, редакции, утверждения, материалы, журналы и прототипы. Старое хранилище остаётся резервной копией. Миграция не выполняется автоматически.
- **Перенести** — подготовить проверенную копию по новому пути и переключить Tandem на неё. Исходная папка остаётся на месте. Перед переносом остановите работу проекта и внешние редакторы.
- **Независимая копия** / **Открыть как копию** — создать новый проект с историей исходного, но независимой дальнейшей работой. Обычная копия в Finder сохраняет тот же ID; Tandem предложит явно выбрать перенос или независимую копию.
- **Указать расположение** — найти перемещённую папку или восстановить подключение после потери доступа. Недоступный проект остаётся видимым вместе с последним путём и причиной.
- **Убрать из списка** сохраняет файлы; проект можно открыть снова. Для старой общей базы сначала нужен перенос. Переименование меняет название в Tandem, путь остаётся прежним. Есть открытие в файловом менеджере и копирование пути.

В папке проекта находятся `docs/` (Markdown-редакции), `materials/` (оригиналы вложений), `prototypes/` (код) и скрытая `.tandem/` (база истории, журналы и снимки). Для ручного переноса или резервной копии **остановите Tandem и копируйте папку целиком, включая скрытые файлы**. Авторизация CLI, сведения о подписках и браузерные черновики в неё не входят; на другом компьютере нужны свои CLI и инструменты сборки.

Правки существующих файлов в `docs/` обнаруживаются в интерфейсе. «Принять новой редакцией» сохраняет правку и запись в журнал, не изменяя прежнего утверждения. Нужен непустой UTF-8 Markdown до 600 КБ. Произвольный новый документ добавляйте через «Материалы».

Во время активной работы проверяется доступность записи: при пропаже папки или диска запрос отменяется. Сохраняются данные, успевшие попасть на диск; незавершённый ответ может потребовать повтора после восстановления. Два экземпляра Tandem не могут одновременно открыть одну папку. Синхронизация работающей базы через облачную папку и одновременная работа разных машин не поддерживаются; распознанные сетевые тома отклоняются. Сетевые workers — отдельный следующий этап.

Перенос пропускает восстанавливаемые `node_modules`, `.venv`, `__pycache__`; зависимости на новом месте нужно установить заново. Символические ссылки и специальные файлы останавливают перенос с объяснением. Лимит копируемого дерева — 4 ГБ / 100 000 файлов. После сбоя исходные данные сохраняются, незавершённая папка помечается; автоматического продолжения переноса пока нет, для повторной попытки выберите другое имя.

## Статусы, лимиты и восстановление (0.5)

Карточки Codex и Claude показывают вход, текущую работу, сведения о лимитах, время их получения и причины недоступности. При остатке не более 20% появляется предупреждение, не более 5% — усиленное. Если CLI сообщил предупреждение без процента, Tandem показывает его без выдуманных чисел. Предупреждения видны во всех разделах, записываются в общий диалог и журнал активного проекта.

- **Codex:** отдельный `account/rateLimits/read` через официальный app-server, без создания разговоров и генерации. Опрос общий для проектов и вкладок, обычно раз в минуту; при сбое интервал увеличивается до восьми минут. Кнопка проверки использует тот же ограничитель частоты.
- **Claude Code:** собственные события `rate_limit_event` во время реальных запросов; поддерживаются статус, необязательные проценты и время сброса. До первого события остаток может быть неизвестен. В карточке есть «Проверить доступность»: Tandem отправляет короткий запрос выбранной модели через подписку, без материалов проекта. Запрос расходует лимит; при фоновом опросе он не отправляется. Успех подтверждает ответ модели на момент проверки, но не выдумывает проценты остатка. Результат, модель и время сохраняются. Повтор — не чаще раза в минуту, без автоматических повторов; проверка ограничена 45 секундами и не запускается одновременно с другой работой Claude. Конфигурация statusline и файлы авторизации не изменяются.
- Ошибка чтения статистики не означает исчерпанный лимит. Старые значения помечаются; разные окна лимитов не усредняются. Прошедшее время сброса само по себе не доказывает восстановление. «Разрешить повторную проверку» в панели участников только разрешает следующий рабочий запрос. Отдельная кнопка «Проверить доступность» в карточке Claude действительно отправляет проверочный запрос. Обычный запуск обсуждения также обновляет состояние по реальному ответу; открывать терминал для этого не нужно.
- Краткий обрыв связи вызывает ограниченные повторы с ожиданием 3, 10, 30 и затем до 60 секунд. При solo после повторных ошибок пробуется второй участник. После исчерпания попыток цикл остаётся на паузе. «Остановить ожидание» отменяет повторы. Ожидание не расходует активные минуты прототипа; уже выполненные этапы не повторяются.
- После остановки Tandem или перезагрузки цикл восстанавливается на паузе с причиной и кнопкой продолжения. Частичный ответ не считается готовым; прерванные проверки сохраняют предыдущую попытку. Время сна не добавляется к активному бюджету при обнаружении длительного перерыва.
- Закрытие браузера не останавливает запущенный сервер. Если браузер теряет связь с ним, интерфейс честно сообщает, что состояние работы неизвестно, и переподключается. Пропажа интернета при работающем локальном сервере — отдельная ситуация: сохранённые данные остаются доступны.

Неотправленный текст автоматически сохраняется в localStorage этого браузера: идея, критерии, уточнения, вставленный материал, доработка и настройки/заметки прототипа. Если браузер запрещает сохранение или место закончилось, появляется предупреждение. Черновики не синхронизируются между браузерами; выбранный, но ещё не загруженный файл потребуется выбрать заново. Добавленные материалы хранятся на сервере.

Изменяющие запросы имеют устойчивый ID и квитанцию в SQLite. Потеря ответа не создаёт повторное сообщение, проект или вложение при повторной отправке того же действия. Если сервер прервался между действием и сохранением квитанции, повтор не выполняется вслепую: интерфейс предлагает проверить результат и лишь затем явно разрешить новую попытку. Это защищает локальные действия Tandem; прерванный запрос к ИИ при повторе может ещё раз израсходовать часть лимита подписки.

## Установка и запуск

Для сборки нужны Git, Go 1.24+ и Node.js 22.12+. SQLite отдельно устанавливать не нужно. На macOS с Homebrew Go и Node.js можно установить командой `brew install go node`.

Клонируйте репозиторий в выбранную папку и установите зависимости. Для этих шагов требуется интернет:

```sh
git clone https://github.com/westman2000/tandem.git
cd tandem
go mod download
npm ci
npm run build
```

Соберите и запустите приложение на macOS или Linux:

```sh
go build -o tandem .
./tandem
```

На Windows (PowerShell):

```powershell
go build -o tandem.exe .
.\tandem.exe
```

Готовый бинарный файл не входит в Git-репозиторий: он появляется после сборки. Все команды после `cd tandem` выполняются из корня клона.

Откройте <http://127.0.0.1:4317>. Для остановки сервера нажмите Ctrl+C. Незавершённый цикл останется на паузе; после следующего запуска его можно продолжить в браузере.

После изменения исходников повторите сборку интерфейса и приложения. На macOS/Linux команда `./scripts/start.sh` выполняет обе сборки и запускает сервер. Для обновления только браузерного интерфейса без перезапуска сервера используйте `./tandem --ui web/dist`, затем `npm run build` и обновление страницы.

## Подключение агентов

Для реальных обсуждений нужны официальные [Codex CLI](https://learn.chatgpt.com/docs/cli) и [Claude Code](https://code.claude.com/docs/en/setup) с действующими подписками. Адаптеры разработаны по интерфейсу Codex CLI 0.160.1 и Claude Code 2.1.296; более старые версии могут не поддерживать используемые флаги.

Войдите в обычном терминале:

```sh
codex login
claude auth login --claudeai
```

В разделе **Подключения** нажмите «Проверить». Tandem не принимает пароли, не извлекает токены и не реализует собственный OAuth. Официальные клиенты хранят авторизацию сами. Сервер должен работать под тем же пользователем ОС и видеть `codex` и `claude` в PATH. В изолированной среде CLI может не видеть связку ключей macOS, даже если вход доступен из обычного терминала.

Режим подписок удаляет переменные API-ключей, переопределения API URL и переключатели сторонних провайдеров из окружения дочернего процесса. Перед запуском требуется подтверждение входа через подписку. При распознанной ошибке входа, лимита или сети действует выбранная политика: остановиться либо продолжить доступным участником. Автоматического перехода на платный API или демо нет. Используются ограничения и правила ваших подписок; Tandem не отменяет их.

## Как работать

1. Создайте проект и опишите идею. Можно вставить готовый большой текст прямо в описание.
2. В «Материалах» добавьте файлы или нажмите «Вставить текст». Назначьте роль: требования, черновик, справочник или вдохновение.
3. При необходимости раскройте «Работать самостоятельно до готовности», задайте критерии и число проверок: от 1 до 10, по умолчанию 5.
4. Выберите «Мои подписки» и начните обсуждение.
5. Читайте общий диалог или сообщения отдельного агента. Уточнения можно адресовать обоим или одному; они поступают при следующем запросе к соответствующему агенту, а не прерывают уже начавшийся ответ.
6. На вкладке «Документ» появится черновик, затем исправленная версия. Его можно скопировать и скачать как Markdown.

Новый цикл в том же проекте использует последнюю предыдущую версию документа того же режима. Старые диалоги остаются в «Истории». Материалы нового цикла могут отличаться от старого.

### Автономная доработка

- Codex и Claude независимо предлагают идеи.
- Оба получают предложения друг друга и дают критические замечания.
- Codex готовит цельный черновик; Claude проверяет его.
- Codex исправляет документ; Claude проверяет результат по критериям готовности.
- При замечаниях последние два действия повторяются в пределах заданного лимита.

Минимальный полный цикл — 8 ответов. Максимум — `6 + 2 × число проверок`: по умолчанию 16 (5 проверок), максимум 26 (10 проверок). Каждый ответ ограничен таймаутом 20 минут. При недоступности участника можно продолжить одним агентом; прочие ошибки останавливают цикл с сохранением результатов.

**Продолжить доработку** в обсуждении или под документом создаёт связанный цикл из пар «исправление → проверка», без повторения идей и черновика. Он получает документ, последние замечания, прежние материалы, критерии, модели и адресованные агентам уточнения. Можно добавить новое уточнение и выбрать от 1 до 10 дополнительных проходов (по умолчанию 5); это до 20 ответов. Предыдущий цикл остаётся в истории. Для смены материалов или моделей используйте «Следующая версия».

**Остановка без улучшения:** после исходной проверки две последовательные оценки «нет существенного улучшения» завершают цикл с объяснением. Есть запасная проверка трёх одинаковых рецензий и версий документа. Это оценка проверяющего агента, а не объективный измеритель качества; работа может быть продолжена вручную.

### Недоступный участник и независимое ревью

Перед обсуждением или подготовкой прототипа выберите **«Продолжить доступным агентом»** (начальное значение в новом интерфейсе) либо **«Остановиться и ждать»**. Если лимит Claude уже закончился, укажите **«Claude сейчас недоступен»**: запросов к нему не будет. Для одиночной работы достаточно одного CLI с подтверждённым входом по подписке. Старые циклы сохраняют политику ожидания; изменить её можно в блоке «Участники» после паузы.

При распознанном отказе сервиса, лимите, потере входа или отсутствии CLI незавершённая задача передаётся второму участнику. Сохранённые этапы повторно не выполняются. В сообщениях и журнале указаны фактический исполнитель, модель и кому задача была назначена. Если автор проверяет собственный документ или код, результат называется **самопроверкой** и остаётся отметка **«Ожидает независимого ревью»**. Число проходов и лимиты прототипа не увеличиваются. Если недоступны оба, цикл останавливается, результаты сохраняются.

Ошибки формата ответа, смена закреплённой модели, ошибки файлов и команд проверок не являются поводом переключать агента. Обычный текст ответа со словами «rate limit» также не запускает переключение. Неизвестный формат ошибки CLI показывается пользователю; агента можно временно отключить вручную. Остаток квоты и время её сброса Tandem не определяет. Нет автоматического перехода на API-оплату, другую модель или нового провайдера.

После восстановления доступа можно нажать **«Доступ восстановлен»**, затем продолжить приостановленный цикл. Для завершённого документа, плана или выбранной сборки есть **«Запросить независимое ревью»**: один запрос второму агенту, с таймаутом 20 минут, без повторного запуска всего обсуждения. Независимая проверка никогда не передаётся автору. Она сохраняется отдельной записью; старые ответы, утверждения, код и результаты проверок не переписываются. Для сборки берутся исходники её Git-коммита, включая исторические версии. Найденные замечания доступны следующей доработке. Автоматического фонового опроса лимитов и повторных попыток нет.

### Выбор моделей

Для Codex и Claude модель выбирается отдельно перед запуском: «По умолчанию в CLI», предложение из списка или точный ID вручную. Выбор передаётся через `--model`. Список берётся из локального каталога Codex, известных псевдонимов Claude, дополнительных вариантов его локального каталога и истории Tandem. Список не гарантирует доступ по подписке; отказ CLI показывается как ошибка, автоматического переключения на другую модель нет.

После первого ответа Tandem сохраняет фактическое имя модели и передаёт его во всех следующих запросах цикла, включая возобновление после перезапуска. Для Claude имя берётся из сообщения `assistant`, для Codex — из метаданных `turn_context` точной локальной сессии. Если определить модель не удалось или она изменилась, запрос не принимается как успешный этап. Имена видны у ответов, в карточках агентов и в истории. Старые ответы не получают выдуманных меток: при запуске версии 0.2 из CLI-журналов восстанавливается только последняя известная модель старого цикла.

Источники интерфейса CLI: [официальная документация Codex](https://learn.chatgpt.com/docs/developer-commands?surface=cli), [настройка моделей Claude Code](https://code.claude.com/docs/en/model-config). Оба инструмента используют существующий вход через подписку; ключи и токены Tandem не читает.

Готовность — заключение проверяющего агента, а не гарантия идеального ТЗ. Если достигнут лимит проходов, интерфейс явно показывает оставшиеся замечания. Важные допущения и вопросы для пользователя должны оставаться в документе.

**Демо** — отдельный режим без запросов к моделям. Показывает заранее подготовленный пример игры. Он не анализирует ваши тексты и файлы; каждый ответ помечен. Демодокументы не используются как контекст реальных обсуждений.

### Файлы и ограничения

- UTF-8: TXT, Markdown, JSON, CSV, YAML, XML и распространённые файлы кода.
- DOCX: основной текст, включая текст таблиц. Без изображений, комментариев, колонтитулов и форматирования.
- PDF: текстовый слой, если установлен `pdftotext` (`brew install poppler` на Mac). Сканированные страницы и изображения не распознаются.
- Не более 12 МБ на файл, 20 материалов на проект, 300 КБ извлечённого текста на материал и 600 КБ на проект. Слишком большие материалы отклоняются явно. Фактическое окно контекста модели может быть меньше этих ограничений.

При запуске сохраняются исходные файлы, извлечённый текст и SHA-256. Оба агента получают один снимок текста. Новые загрузки не изменяют уже начатое обсуждение. Удаление материала из списка не удаляет исторические снимки; оно исключает его из будущих циклов.

## Локальные данные и доступ

Новые проекты хранятся в выбранных самостоятельных папках. Общий каталог содержит список известных проектов, настройки и сведения о подписках. Новая установка использует системный каталог конфигурации `Tandem` (на macOS — `~/Library/Application Support/Tandem`). Если рядом с бинарником или в каталоге запуска найдена прежняя общая `.tandem/`, она продолжает использоваться без автоматического переноса. `--data /path/to/data` явно задаёт общее хранилище. Его тоже следует резервировать после остановки сервера.

Данные не зашифрованы приложением; создаваемые папки доступны только текущему пользователю. Папка проекта переносится отдельно от общего каталога.

CLI дополнительно ведут свои сессии и данные в собственных каталогах, вне `.tandem`. Tandem сохраняет только точные ID сессий для каждого агента и цикла; не использует «последнюю сессию».

В браузере видны ответы, краткие объяснения и события работы. Скрытые reasoning/thinking-блоки не запрашиваются и не сохраняются в журнал Tandem. Материалы и запросы реального цикла отправляются сервисам выбранных агентов; локальное хранение истории не означает офлайн-работу моделей.

Сервер слушает только loopback. Запросы проверяются по Host, Origin и токену изменяющих запросов. Это однопользовательское локальное приложение, без сетевой авторизации и многопользовательской изоляции. Не выставляйте его в интернет через прокси.

При обсуждении документов Claude запускается без инструментов; Codex — с read-only sandbox и отключённым веб-поиском. Политики организации, заданные самим официальным клиентам, продолжают действовать.

## Проверки и переносимость

```sh
npm run build
go test -race ./...
go vet ./...
./scripts/build-release.sh
```

В ограниченной среде, где системный Go build cache недоступен:

```sh
GOCACHE="$PWD/.tools/go-build" go test -race ./...
```

Готовый бинарный файл включает интерфейс и SQLite. Node.js, Go и отдельный SQLite для его запуска не требуются. Для реального обсуждения всё равно нужны разрешённые к запуску официальные CLI и их авторизация. Сборка бинарников для нескольких ОС не заменяет проверку на реальных Windows/Linux; текущее целевое окружение разработки — macOS ARM64.

Корпоративный запрет на запуск сторонних программ, вход в ИИ-сервисы или передачу документов нельзя обойти переносным бинарником. Возможная будущая схема — браузер на рабочем компьютере и разрешённые агенты на другом компьютере, с отдельной сетевой авторизацией и согласованными правилами доступа.

## Что дальше

1. Проверить реальные подписочные циклы и адаптеры на нескольких версиях CLI.
2. Подключаемые CLI-агенты: отделить роли «Автор» и «Рецензент» от названий инструментов, добавить выбор CLI и модели для каждого участника. Следующий адаптер — **Antigravity CLI (`agy`)**, с официальной авторизацией через аккаунт. Планируемые пары: Codex + Claude, Codex + Antigravity, Claude + Antigravity. [Объём работ и критерии готовности](docs/architecture.md#план-подключаемых-cli-агентов).
3. Улучшать сравнение редакций, передачу уточнений и работу с крупными проектами.
4. Расширение разработки: параллельные задачи в Git worktrees, интеграция изменений нескольких авторов, большие проекты.
5. Удалённые workers: TLS, аутентификация, журнал доставки, возобновление после разрыва связи и разрешения на файлы.

Antigravity, произвольные CLI-участники и удалённые машины пока не реализованы. В режиме прототипа доступны Codex и Claude с выбором автора и ревьюера. Проект написан самостоятельно; [llmcouncil](https://github.com/rachittshah/llmcouncil) послужил отправной точкой обсуждения, его код не скопирован.

Архитектура и протокол сохранения описаны в [docs/architecture.md](docs/architecture.md).

## Редакции ТЗ и создание прототипа (0.3)

На вкладке **Документ** доступны черновики и исправления всех циклов: выбор редакции, построчное сравнение, скачивание и кнопка **Утвердить редакцию**. Утверждение сохраняет полный текст и SHA-256. Демонстрационные ответы утверждать для реальной разработки нельзя. «Продолжить доработку» по-прежнему продолжает последнюю редакцию выбранного цикла; прототип можно создать по любой утверждённой редакции.

1. Утвердите выбранную редакцию и нажмите **Создать прототип по этой редакции**.
2. Опишите гипотезу (по умолчанию игровая механика), выберите платформу прототипа или рекомендацию агентов. Платформа будущего продукта задаётся отдельно. Укажите новый проект либо чистый локальный Git-репозиторий для отдельной копии; при желании выберите родительскую папку внутри папки проекта. Выберите автора, лимиты итераций, времени и повторных неудач.
3. Автор предлагает план, второй агент рецензирует его, автор выпускает итоговый план. Видны упрощения, критерии, запуск, инструменты и точные команды. План можно вернуть на доработку.
4. Проверьте и утвердите план. Только после этого Tandem создаёт отдельный Git-репозиторий и начинает кодинг. Исходный репозиторий сохраняется; публикация и push не выполняются.
5. Во вкладке **Сборки** видны checkpoint, изменения файлов, реальные команды/вывод/коды выхода, рецензия и ограничения. Можно скачать исходники, принять сборку, вернуться к предыдущей или дать обратную связь для нового ограниченного цикла.

Для статического браузерного прототипа после успешных проверок сохраняется отдельная копия файлов из `previewDirectory`. **Подготовить просмотр → Открыть прототип** запускает её на отдельном локальном порту. Вкладка ограничена browser sandbox и не имеет доступа к API Tandem. Это просмотр статических файлов; проекты с собственным сервером, устройства и эмуляторы запускаются по инструкции из плана. Старые просмотры сохраняют файлы своей сборки. Одновременно работает один сервер просмотра; новый просмотр закрывает предыдущий.

**Журналы обязательны:** диалог, решения, изменения и результаты проверок сохраняются локально. **Скачать весь журнал** выгружает JSON со всеми событиями, ответами, планом, снимком ТЗ и сборками. Экран событий показывает последние 500 записей, выгрузка содержит все. Вывод одной команды ограничен 128 КБ и явно отмечает обрезку. Скрытые рассуждения не сохраняются.

Автор передаёт структурированные изменения текстовых файлов; Tandem применяет их и исполняет команды утверждённого плана. Это ограничение первой реализации: до 100 файлов / 3 МБ в одном ответе, контекст исходников до 300 текстовых файлов / 2 МБ; двоичные ресурсы и symlink автор не создаёт. Автором может быть Codex или Claude, второй участник становится ревьюером. Используются прежние официальные подписочные CLI и модели выбранного обсуждения.

Команды запускаются локально с правами процесса Tandem; отдельная Git-копия не является контейнером или системной песочницей. Приложение не устанавливает отсутствующие системные инструменты. До старта проверяется наличие программ в PATH; наличие полного SDK и работоспособность сборки подтверждаются командами, а устройство и механика — отдельной ручной проверкой. В браузере можно смотреть журналы, но успешный build не означает, что игра уже проверена пользователем.

Пауза завершает активный CLI/команду и сохраняет работу. После перезапуска незавершённые проверки отмечаются прерванными; продолжение повторяет их и сохраняет предыдущую попытку. Суммарное активное время сохраняется, его можно явно продлить после остановки. Обратная связь предоставляет новый бюджет без удаления прежних сборок. Возврат к checkpoint разрешён только при чистой рабочей папке, чтобы не удалить пользовательские изменения.
